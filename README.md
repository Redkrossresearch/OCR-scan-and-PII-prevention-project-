# 🔒 OCR-PII Detection Backend

A FastAPI-based backend for an OCR (Optical Character Recognition) and PII (Personally Identifiable Information) Detection System. This project extracts text from uploaded documents/images, detects sensitive information, and provides APIs for secure document analysis.

---

## 📌 Features

- 📄 OCR text extraction from images and PDFs
- 🔍 PII detection (Aadhaar, PAN, Email, Phone Number, etc.)
- 🛡️ Digital Signature Verification
- 💧 Watermark Detection
- ✂️ Tamper Detection
- 📊 Risk Assessment
- 👤 Ownership Tracking
- 🏷️ Document Classification
- 📈 Dashboard Analytics
- 📑 Report Generation
- 🚀 REST API built with FastAPI
- 📂 File Upload Support
